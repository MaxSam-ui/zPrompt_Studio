# Offline guide / Guida offline

- **Italiano:** apri `help.html` nel browser.
- **English:** open `help.en.html` in your browser.

Use the **?** button in Studio, then choose English or Italiano at the top of the guide.
Usa il pulsante **?** in Studio e scegli English o Italiano in cima alla guida.

Both guides include offline search and Print / PDF. GitHub displays HTML source: download the repository to read the formatted manual locally.
Entrambe le guide includono ricerca offline e Stampa / PDF. GitHub mostra il sorgente HTML: scarica il repository per leggere il manuale impaginato.
